Part 1: Fun with Filters


Part 1.1: Convolutions from Scratch!

To start this project, I created functions to perform 2D convolutions from scratch using NumPy. One of the functions uses four for-loops to iterate through each pixel in the image and apply the filter, while the other function uses two for-loops and to apply the filter.
Here's the code for the four for-loops implementation: 
                    def four_loop_convolution(img, filter):
                        # move left to right
                        img_h = img.shape[0]
                        img_w = img.shape[1]
                        # channel = img[2]

                        # flip the filter vertically and horizontally
                        filter = np.flip(filter, axis=0)
                        filter = np.flip(filter, axis=1)

                        filter_h = filter.shape[0]
                        filter_w = filter.shape[1]

                        # calculate resulting image dimensions as we did in 189 for convolutions
                        output_h = img_h - filter_h + 1
                        output_w = img_w - filter_w + 1

                        # initialize empty output array
                        output_arr = np.zeros((output_h, output_w))

                        for h in range(output_h):
                            for w in range(output_w):
                                # loop over the filter dims
                                for k_h in range(filter_h):
                                    for k_w in range(filter_w):
                                        # convolve
                                        output_arr[h, w] += filter[k_h, k_w] * img[h + k_h, w + k_w]

                        return output_arr

And here's the code for the two for-loops implementation: 
                    def two_loops_convolution(img, filter):
                        # move left to right
                        img_h = img.shape[0]
                        img_w = img.shape[1]
                        # channel = img[2]

                        # flip the filter vertically and horizontally
                        filter = np.flip(filter, axis=0)
                        filter = np.flip(filter, axis=1)

                        filter_h = filter.shape[0]
                        filter_w = filter.shape[1]

                        output_h = img_h - filter_h + 1
                        output_w = img_w - filter_w + 1

                        # initialize empty output array
                        output_arr = np.zeros((output_h, output_w))

                        for h in range(output_h):
                            for w in range(output_w):
                                # slice instead of using two more loops
                                region = img[h:h+filter_h, w:w+filter_w]
                                # multiply and compute sum
                                output_arr[h, w] = np.sum(region * filter)

                        return output_arr
I tested both implementations as well as scipy.signal.convolve2d on a grayscale sample image of myself and compared the results:
  • Both of my implementations produced the same output as the scipy output. They also handled boundaries the same way (with zero-padding).
  • For an image of about 2200 x 1250, the four-loops implementation took over a minute to run. The two-loops implementation took about 6 seconds to run. The scipy implementation took less than a second to run.

Part 2: Fun with Frequencies!


Part 2.1: Image "Sharpening"

Images look sharper when they have higher frequencies. For this subpart, I created an unsharp mask filter in a single convolution to increase the high frequency content of an image.
To create this filter, I first created a Gaussian filter with a size of 9x9 and a standard deviation of 2. Then, I subtracted this Gaussian filter from a unit impulse of the same size to create the unsharp mask filter! I used an alpha parameter to control the amount of sharpening done by the filter.
By applying this filter to images, I was able to sharpen them! Below are some examples of images before and after applying the unsharp mask filter with alpha=1.5:

Part 2.2: Hybrid Images

We can create hybrid images using the approach described in the SIGGRAPH 2006 paper by Oliva, Torralba, and Schyns. The idea is to combine the low frequency content of one image with the high frequency content of another image to create a hybrid image that changes depending on the viewing distance.
As an example, I first aligned the two images by aligning their eyes on top of each other. Then, I ran a low-pass filter (a gaussian with ksize=50, sigma=18) on Derek, a human, and a high-pass filter (impulse minus gaussian with ksize=101, sigma=30) on Nutmeg, a cat. I combined the low-frequency image of Derek with the high-frequency image of Nutmeg to create a hybrid image.

2.3: Gaussian and Laplacian Stacks

I created Gaussian and Laplacian stacks of images of an orange and an apple.
  • A Gaussian stack is created by repeatedly applying a Gaussian filter to an image to create a series of increasingly blurred images.
  • A Laplacian stack is created by taking the difference between consecutive images in the Gaussian stack.
