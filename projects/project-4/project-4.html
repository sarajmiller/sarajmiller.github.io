Project 4: Neural Radiance Field (NeRF)


In this project, I implemented a basic version of Neural Radiance Fields (NeRF) to generate novel views of 3D scenes from a set of 2D images.

Part 0: Calibrating the Camera and 3D Scanning

To start, I took over 30 images from varying distances and angles of AruCo markers to calibrate my camera using OpenCV. I used cv2.calibrateCamera() to compute the camera intrinsics, and cv2.solvePnP() to estimate the camera pose for each image. Finally, I was able to put everything together to create a NeRF representing a 3D image. I'll go through how I did it step-by-step, as well as showing an example using the Lego dataset from the original NeRF paper.

Part 2.1: Creating Rays from Cameras

To start, I implemented some methods to create rays from the camera intrinsics and extrinsics.
The first one was Camera to World Coordinate conversion, which converts camera coords to world coords using the inverse of the camera extrinsics matrix.
Next, I implemented Pixel to Camera coordinate conversion using the intrinsics matrix K. This converts pixel coordinates (u, v) to camera coordinates (x, y, z).
Finally, I implemented Pixel to Ray conversion, which combines the previous two methods to generate rays in world coordinates for each pixel in the image. Part 2.2: Sampling

I implemented sampling rays from images by randomly selecting pixels from the images and converting them to rays. Since pixels are measured at the corners, not in the middle, I added 0.5 to the pixel coordinates when sampling. This method is helpful for training the NeRF model using mini-batches of rays.
Additionally, I implemented sampling points along rays, which samples 3D points along a ray at regular intervals between a near and far distance (typically 2.0 and 6.0). Optionally, I added small random perturbations to the sample positions to improve training.

Part 2.4: Creating the NeRF Model

Now that we are able to sample 3D points along rays, we want to use the network to predict color and density values for those points. I created an MLP similar to part 1, but with some changes:
NeRF MLP Structure
The model starts with 8 layers with 256 hidden units per layer. The input is 3D coordinates with L=10 levels of positional encoding. The output is a density value and RGB color for each point. After the first 8 layers, the network branches into two heads: one for density and one for color. The color head takes in the viewing direction (also with positional encoding, L=4)
